Commands & How to Use

Five straightforward slash commands for web pages, YouTube videos, Incognito Mode, and multilingual help.

🌐 Public Web + Delete Up to 4 results (2 pages)
/search busca:[query] language:[BR|US|ES|FR|DE|IT]

Searches the web and posts a public Embed with up to 4 results across 2 pages, quick link buttons, anti-spam cooldown, and a Delete / Apagar button.

🕶️ Incognito Web Up to 4 results (2 pages)
/incognito search busca:[query] language:[BR|US|ES|FR|DE|IT]

Ephemeral Incognito Mode search with a clean Embed and clickable titles: only the user who ran the command sees both pages of results.

🎬 Public YouTube + Delete 3 videos (3 pages)
/searchvideos search:[query] language:[BR|US|ES|FR|DE|IT]

Searches YouTube and posts the video directly in Discord's native player with Previous/Next buttons for 3 videos, Delete button, and empty-search protection.

🕵️ Incognito YouTube 3 videos (3 pages)
/incognito videos search:[query] language:[BR|US|ES|FR|DE|IT]

Private ephemeral YouTube video search: watch and flip through 3 video results inside Discord with only you able to see them.
