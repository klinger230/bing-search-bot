Commands & How to Use (v4.0)

Streamlined unified slash commands: pick any command and set incognito-mode to True whenever you want private results.

🌐 Web Search + incognito-mode Up to 4 results (2 pages)
/search busca:[query] incognito-mode:[True/False]

Searches the web across 6 regions with up to 4 paginated results, direct link buttons, Delete button, and optional incognito-mode for private ephemeral replies.

🎬 YouTube + incognito-mode 3 videos (3 pages)
/searchvideos search:[query] incognito-mode:[True/False]

Searches YouTube with Discord's native player across 3 paginated videos, Delete button, and optional incognito-mode so only you can watch.

🌍 25 Languages + incognito-mode Auto-detect source
/translate text:[text] incognito-mode:[True/False]

Translates text into 25 supported languages with automatic language detection, Delete button, and optional incognito-mode for private translations.

📰 News Search (NEW v4.0) Paginated + Direct Links
/news query:[topic] incognito-mode:[True/False]

Searches recent news articles by keyword or topic with optional language filtering, multi-page navigation, direct article link buttons, and incognito-mode.

🌦️ Real-Time Weather (NEW v4.0) Temp • Feels Like • Humidity • Wind
/weather location:[city] incognito-mode:[True/False]

Checks real-time weather conditions for any city or location, displaying current temperature, feels-like temperature, sky condition, humidity, and wind speed — publicly or privately via incognito-mode.
